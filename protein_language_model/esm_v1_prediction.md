# E03 预判（R21）：ESM-2 给 cGAS 四位点打分

**写于 2026-10-20 16:53，台式机，装环境和跑模型之前。** 跑完后不改本文件，对照写进 `esm_v1.md`。

## 名词

- **ESM-2**：Meta 2022 年发布的蛋白语言模型，在约 6500 万条 UniRef 蛋白序列上做「完形填空」训练：遮住一个氨基酸，让模型猜它原来是什么。
  猜对的概率高 = 这个位置放这个氨基酸「像天然蛋白」。650M = 6.5 亿参数版本。
- **掩码打分（masked marginal）**：把第 i 位遮住（换成 `<mask>`），模型给出 20 种氨基酸在这一位的概率 p(·)。
- **突变打分 LLR**（log-likelihood ratio，对数似然比）：`LLR(a→b) = log p(b) − log p(a)`，都在「第 i 位被遮住、其余是野生型」时取。
  LLR > 0 = 模型认为换成 b 更「自然」；LLR < 0 = 更不自然。经验上 LLR < −4~−5 的突变多半破坏功能（在 ProteinGym 深度突变扫描基准上 ESM 这样打分与实测的 Spearman 约 0.4~0.5）。
- **组合突变打分**：四点同时换，用两种算法：
  ① 加和：4 个单点 LLR 直接相加（假设互不影响）；
  ② 伪似然差：ΔPLL = PLL(四点突变序列) − PLL(人野生型)，真正考虑位点间互相影响。两者之差 = 模型眼里的「上位效应」（epistasis，位点之间的相互作用）。
- **伪似然 PLL**（pseudo-log-likelihood）：对一条序列每个位置依次遮住，取模型给「真实那个氨基酸」的 log p，全部加起来。**PLL/L**（除以长度）= 平均每个残基有多「像天然蛋白」，可跨不同长度序列比较。
- **秩**：在第 i 位 20 种氨基酸中，按模型概率从高到低排第几。

## 预判

| # | 预判 | 指标 / 怎么判对错 |
|---|---|---|
| E1 | 人背景上 4 个单点「人型 → 裸鼹鼠型」（D431S、K479E、L495Y、K498T）的 LLR 都在 **[−4, +1]**，没有一个是「强破坏性」；最负的是 L495Y（疏水 → 芳香、体积变大）或 K479E（电荷反转） | 4 个 LLR 数值；判对 = 全部 ∈ [−4, +1] |
| E2 | 四点组合加和 LLR 在 **−8 ~ −2**；ΔPLL 与加和相差不到 30%（模型看不出明显上位效应——4 个位点在序列上相距 3~67 位，模型主要靠局部） | 加和值；\|ΔPLL − 加和\| / \|加和\| < 0.3 |
| E3 | 模型**看不出**裸鼹鼠型的特殊性：在人背景上，4 个位点中至少 3 个位点人型残基的秩高于裸鼹鼠型；且裸鼹鼠型 LLR 与「该位点在 262 种哺乳动物里出现过的其他非人型残基」的 LLR 分布无系统差别（不落在最低 10%，也不落在最高 10%） | 秩；在同位点「自然出现过的替换」LLR 中的分位数 |
| E4 | **背景依赖（固化）**：在裸鼹鼠自己的 cGAS 上做反方向「裸鼹鼠型 → 人型」，LLR 也 ≤ 0（每条序列的模型最偏好自己现有的残基）。即同一替换在两个背景上符号相反或都偏负 | 裸鼹鼠背景 4 个反向 LLR；判对 = 至少 3 个 ≤ 0 |
| E5 | 各物种整条 cGAS 的 PLL/L 主要按类群分层：灵长目 PLL/L 高于啮齿目中位数（训练数据里人和模式动物多，模型对它们「更熟」）；**与 LQ 的 Spearman \|ρ\| < 0.2** | 分目中位数；ρ（只描述，不报 p） |
| E6 | 每个物种在 4 个位点上的「裸鼹鼠型偏好」S_nmr = Σ_i [log p(裸鼹鼠型) − log p(人型)]（在该物种自己的序列上遮住第 i 位）——与命中数强相关（几乎是定义上的），但**豪猪亚目以外**与 LQ 的 \|ρ\| < 0.2 | 两个 ρ |
| E7 | 资源：ESM-2 650M 能在 16GB 显存跑（fp32 权重约 2.6GB）；批量遮罩时峰值 < 8GB；全部约 268 条 × ~530 位置 ≈ 14 万次前向，**总 GPU 时间 < 20 分钟**；装 Blackwell（sm_120）能用的 torch 是最可能卡住的一步 | 显存峰值、耗时、是否需要降 150M |

## 预期的整体结论

ESM-2 是「通用自然性」模型，不懂寿命；cGAS C 端这一段在哺乳动物里本身就多变（v1 位点表里人型在 479、495 位甚至是少数派），
所以它大概率**给裸鼹鼠四个替换都打「中性偏低」分，既不说有害也不说特殊**。若出现某个位点 LLR < −5 或明显上位效应，那才是值得追的信号。
